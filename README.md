# MISHA BANK — своя валюта @ (собаки)

Онлайн-банк со своей валютой «@» (собаки). Регистрация по нику и ПИН-коду, переводы между игроками, общая база — всё работает между разными устройствами.

## Как запустить

1. Открой `index.html` в браузере для локальной проверки.
2. Загрузи файлы проекта в репозиторий GitHub.
3. В репозитории открой **Settings → Pages**, выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. После публикации сайт появится по адресу `https://<твой-ник>.github.io/<название-репозитория>/`.

## Возможности

- 🪪 Регистрация с уникальным ником и входом по ПИН-коду (4–6 цифр).
- 💰 Стартовый баланс 1000 @ и ежедневный бонус 500 @.
- 💸 Переводы @ другим игрокам по нику с сообщением.
- ⛏ Работа: тапай, зарабатывай @ (анти-автокликер защищает от ботов). Улучшай уровень работы за @.
- 🎰 Игры: подброс монеты (×1.9), кубик (×5).
- 📜 Ежедневные квесты с наградами.
- 🏆 Достижения и статистика.
- 👑 Таблица лидеров и история операций.
- 🎨 Выбор аватарки из эмодзи.
- 📤 Экспорт/импорт JSON для резервной копии.
- 🛠 Панель админа (ник `admin`, ПИН `9898`).

## Технические детали

- Чистый HTML/CSS/JS без фреймворков.
- Хранилище: textdb.online — общая база, CORS открыт.
- Адаптивный дизайн, mobile-first.
